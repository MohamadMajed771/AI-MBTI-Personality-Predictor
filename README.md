# AI MBTI Personality Prediction System

## Overview

The AI MBTI Personality Prediction System is a machine learning-based web application that predicts a user's Myers-Briggs Type Indicator (MBTI) personality type using both natural language processing (NLP) and questionnaire responses.

The system combines text-based personality analysis with survey-based predictions to generate more robust and accurate MBTI classifications.

---

## Features

* Predicts all four MBTI dimensions:

  * Introversion (I) / Extraversion (E)
  * Intuition (N) / Sensing (S)
  * Thinking (T) / Feeling (F)
  * Judging (J) / Perceiving (P)

* Uses Natural Language Processing (NLP) to analyze user-written text.

* Uses TF-IDF feature extraction for text representation.

* Trains Logistic Regression classifiers for each MBTI dimension.

* Incorporates questionnaire-based personality assessment.

* Combines text-based and questionnaire-based predictions using PyTorch neural-network meta models for final MBTI classification.
* Provides predictions through a user-friendly web interface.

## Dataset

This project was trained using the MBTI Personality Dataset available on Kaggle.

Dataset link:
https://www.kaggle.com/datasets/datasnaek/mbti-type

The dataset is not included in this repository to keep the project lightweight.

If you wish to retrain the models, download the dataset and place:

`mbti_1.csv`

in the root project directory.

The trained machine learning models and neural-network meta models are already included, so the web application can run without downloading the dataset.


## How It Works

### Text-Based Prediction

1. User enters a text sample.
2. Text is cleaned and preprocessed.
3. TF-IDF converts text into numerical features.
4. Four Logistic Regression models predict:

   * I/E
   * N/S
   * T/F
   * J/P

### Questionnaire-Based Prediction

1. User answers personality-related questions.
2. Responses are converted into numerical features.
3. Dedicated classifiers predict personality dimensions.

### Meta Model Fusion

The system combines outputs from both prediction pipelines using neural-network-based meta models to produce the final MBTI type.
